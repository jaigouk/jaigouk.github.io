Ruby framework for building LLM-powered systems with reduced complexity. Package domain logic as reusable components that work across assistants, jobs, and services.

- Supports multiple LLM providers (OpenAI, Anthropic, Groq, Gemini, Ollama)
- Tool composition and orchestration for SQL queries, ActiveRecord, vector search, and API calls
- Both legacy text-based reasoning (ReAct) and native provider tool-calling modes
- Designed for Ruby and Rails teams integrating LLM functionality
