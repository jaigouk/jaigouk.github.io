Proxy tool for Google Gemini that enables image and text generation through a Pro subscription without requiring an API key. Provides OpenAI v1 API compatibility for drop-in replacement with existing OpenAI clients.

- CLI for quick generation tasks
- REST API server built with FastAPI
- MCP server integration for AI agents
- Automatic authentication using browser cookies
- Server-Sent Events support for streaming chat completions
