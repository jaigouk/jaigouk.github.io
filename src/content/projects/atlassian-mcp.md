MCP server that brings Jira and Confluence into AI-powered IDEs. Search tickets, look up documentation, and manage work items through natural language — without leaving your editor.

- OAuth 2.0 authentication with encrypted token storage
- Jira tools: search, get ticket details, list assigned tickets
- Confluence tools: search pages, get page content
- Redis caching for performance
- Hexagonal architecture with DDD and strict layer separation
